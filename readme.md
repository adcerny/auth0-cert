# Auth0 Certified Developer Study Guide

This repository contains my personal notes and reference material created while preparing for the **Auth0 Certified Developer Exam** (Okta Developer Certification).

The guide summarises key concepts, API behaviours, and configuration details that are often not fully covered in the official learning materials. It focuses on the kind of fine-grained knowledge needed to perform well in the exam and to gain a deeper understanding of the Auth0 platform in practice.

## About This Guide

The guide is structured to help candidates prepare efficiently for the exam:

1. **Before You Start** – practical study tips, learning resources, and advice on using the official Auth0 training materials  
2. **Core Topics** – explanations and reference notes covering authentication flows, tokens, MFA, organisations, APIs, and other essential areas  
3. **Exam Strategy** – notes on DOMC questions, the practical section, and tips for exam day  

While the notes are designed around exam preparation, they also serve as a useful technical reference for developers working with Auth0 in production environments.
